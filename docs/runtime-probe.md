# Runtime compatibility probe

`scripts/probe-runtime.mjs` is a bounded sample probe for the owner-selected host. It checks the running Node major, launches the configured system Chromium executable through the configured outbound proxy against one owner-selected controlled sample URL, and sends one short strict Structured Outputs request to the explicitly selected model. The browser subprocess receives a small environment allowlist; it does not inherit model or database credentials. The report contains statuses and the selected model name, never the API key or response body.

Run with `MOFLO_OWNER_SELECTED_HOST_ID`, `MOFLO_RUNTIME_SAMPLE_URL`, `CHROMIUM_PATH`, `OUTBOUND_PROXY_URL`, `OPENAI_MODEL`, and the server-side `OPENAI_API_KEY` set by the host's secret manager. The sample URL must be a controlled fixture reachable through the selected proxy. The command returns exit code 2 with a `NOT_PROVEN` report if required configuration is absent or a sample fails. Do not substitute a public company website or a production URL for the fixture.

The Node 22 binary and host Chromium are available for local development, but this does not qualify the deployment topology. A successful sample will prove only that this runtime can render that fixture and that this exact model accepts the small strict schema. It does not prove isolation, proxy enforcement, blocked private destinations, or release readiness.
